# 风险清单（DSH 适配中台）

> 纪律：**风险显式暴露 + 给规避方案 + 标注触发条件**；不确定的一律标风险，绝不默认「应该没问题」。
> 承担风险的是人，所以每条都写清「什么时候会爆、爆了怎么办」。
