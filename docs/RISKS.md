**边界（不可捕获终止，🔴 必修-2「二选一」的方案②）**：`SIGKILL` / OOM / 原生 `abort` **不可捕获**——
探针来不及写结构化结果。此时装配器按**相位信标** `__DSH_PROBE_PHASE__` 归因：
**有信标**（终止发生在插件代码运行期间）→ 插件侧 check `plugin.abnormal_termination`，`hostFatal[]` 保持为空；
**无信标**（终止在宿主装配段）→ `hostFatal[]` → `UPSTREAM_DRIFT`（真上游信号不丢）。
> 为什么不能只「声明边界」了事：声明只解决「静默」，不解决「甩锅」——插件把自己 `kill -9`
